## <div align="center">Install && Use</div>

> AzToolkit is a toolkit for an anonymity team in nudt.

**本地开发安装**

- **使用标准双层结构**
```sh
cd CodexOpen/tools/az_toolkit
pip install -e .
```

- **使用工具库**
```python
from az_toolkit import some_function

# 使用工具中的功能
some_function()
```

### 提取 DataProcesser 解析出的数据

生成多模态数据集的一般步骤顺序：

```
S0_read_timstamp.py
S1_timestamp_match.py
S2_data_stamp_rename.py
S3_extracting.py
S4_select_nearest.py
```
